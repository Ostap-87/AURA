# Дизайн-токены — Aura Robotics

Источник: дизайн-система robot.com, `styles.refero.design`.
Значения помечены: **[шаблон]** — брать буквально, **[производное]** — адаптация под кириллицу и мобильные, приоритетнее шаблона.

---

## Цвета [шаблон]

```
Акцент            #fff65d   единственный хроматический цвет
Канвас            #ffffff   основной фон страницы
Тёплая поверхность #f8f6f3  фон карточек
Тихий разделитель #d9d7d5
Текст третичный   #8f8e8d
Текст вторичный   #727272
Текст основной    #262626   он же фон тёмных секций
Уголь             #2d2d2d
Максимальный акцент #000000  одна кнопка на экран, не больше
```

**Правила:**
- Жёлтый — только фоновые блоки и один акцентный элемент на экран. Никогда не текст, никогда не подложка под текст.
- Чистый чёрный `#000000` — только для одной, самой важной кнопки в поле зрения. Все прочие тёмные элементы `#262626`.
- Ритм секций: белый → парчмент → тёмный → жёлтый.
- Без градиентов. Без теней. Глубина создаётся контрастом цветовых блоков.

---

## Шрифт

**Inter** — шаблон указывает его как замену Yellix.
Подмножество: латиница + кириллица. `font-display: swap`.
Начертания: 400, 500, 600.

Моноширинный для подписей к фото, характеристик и цифр: **JetBrains Mono** [производное].

Без засечек нигде.

Кегли и межстрочные — **[шаблон]**. Трекинг и мобильная колонка — **[производное]**.

**Внимание.** В исходном шаблоне указан трекинг −0.214em при кегле 100px. Это значение не использовать: при кириллице буквы накладываются друг на друга. Максимальный отрицательный трекинг на проекте — −0.02em.

**Минимальные размеры:** текст на сайте не мельче 14px, основной текст 16px, поля форм не мельче 16px — иначе Safari на iOS принудительно увеличивает экран при фокусе.

## Размеры и сетка

```
Базовая единица      4px          [шаблон]
Контейнер            1280px       [шаблон]
Отступ между секциями 64px десктоп / 40px мобильный   [шаблон / производное]
Паддинг карточки     24px         [шаблон]
Промежуток элементов 8px          [шаблон]
```

Все отступы кратны 4.

---

## Радиусы [шаблон]

```
Кнопки                    30px
Теги, пилюли, чипы        24px
Карточки контента         10px
Утилитарные элементы,
фильтры, ячейки таблиц    4px
```

**Разночтение в источнике:** в таблице радиусов карточки указаны как 24px, в описании компонента — 10px с пояснением, что меньший радиус отличает контент от интерфейса. На проекте используем **10px для всех карточек контента** единообразно.

## Компоненты

**Кнопка основная:** заливка `#000000`, текст `#ffffff`, 16px/500, радиус 30px, паддинг 12×24. Одна на экран.

**Кнопка вторичная:** прозрачная или `#ffffff`, граница 1px `#262626`, текст `#262626`, радиус 30px.

**Карточка каталога:** фон `#f8f6f3`, граница 1px `#262626`, радиус 10px, паддинг 24px. На ховере подъём 4px и подсветка обводки, 200 мс.

**Чип фильтра:** радиус 24px, активное состояние — заливка `#fff65d`, текст `#262626`.

**Жёлтый акцентный блок:** фон `#fff65d` на всю ширину, заголовок `#262626`, без карточек и рамок внутри — жёлтый сам является контейнером.

**Тёмная полоса:** фон `#262626`, текст `#ffffff`, для цитат и акцентных утверждений.

## Фотография

Полноэкранные фото без рамок и скруглений [шаблон].
Исключение: карточки каталога — поверхность `#f8f6f3`, радиус 10px, граница 1px.

Съёмка ведётся на телефон и подаётся документально. **Подпись к каждому кадру обязательна**, моноширинным шрифтом 12px, цвет `#727272`: что снято, где, когда, серийный номер если виден. Без подписи телефонный кадр читается как небрежность, с подписью — как свидетельство с места.

Вертикальные ролики 9:16 не вставляются в горизонтальные полноэкранные блоки — только в отдельную сетку.

## Анимации

```
Появление секции    fade + сдвиг 24px, 400 мс, ease-out, один раз
Ховер карточки      подъём 4px + подсветка обводки, 200 мс
Каскад карточек     задержка 60 мс между соседями
Счётчики            отсчёт при попадании в область видимости
```

Не более двух анимированных элементов на экран.
`prefers-reduced-motion` отключает всё.
На мобильных отключаются: закреплённые схемы, параллакс, каскадные появления, фоновые видео.

**Запрещено:** параллакс во всю высоту, частицы, кастомный курсор, прелоадер, автовоспроизведение со звуком.

---

## Навигация [отступление от шаблона]

Шаблон предполагает плавающую пилюлю. **Используем обычную панель с выпадающими списками** — пилюля не вмещает три направления и 15 категорий.

Язык пилюль сохраняется для кнопок, тегов и чипов, но не для навигации.

На мобильных и планшетах в вертикальной ориентации — кнопка меню, открывающая полноэкранный слой с аккордеонами по направлениям.
